# LIT 예약 메시지 (자동 번역) — PRD 초안

## 배경
LIT는 카페·가게가 여행자의 짐을 맡아 주는 짐보관 서비스다. 손님 대부분은 외국인 여행자(영어·일본어·중국어)이고, 사장님은 대부분 한국어만 쓴다.
지금은 손님과 가게가 연락할 방법이 전화·문자뿐이라 "30분 늦어요", "입구가 어디예요?", "오늘 6시에 일찍 닫아요" 같은 짧은 연락이 언어와 해외 번호 때문에 막힌다. 그 결과 헛걸음·노쇼·낮은 별점이 생긴다.
경쟁사 링크킵은 예약자와 가게가 채팅할 수 있고, 다른 언어면 번역해서 보여 준다.

## 목표
- 손님과 사장님이 **서로 자기 언어로** 짧은 연락을 주고받는다.
- 사장님에게 새 일을 거의 얹지 않는다 — 대부분 버튼 한 번(빠른 답장)으로 끝난다.
- 전화번호·이메일을 서로에게 보여 주지 않는다.

## 사용자
- **사장님(점주)**: 망원동 카페 사장님 같은 1~2인 매장. 손님 응대·음료 만들기 사이에 폰을 본다. 한국어만 쓴다. LIT 매장 앱(점주 앱)을 쓴다.
- **손님(여행자)**: 일본·미국·대만 등에서 온 여행자. 로그인 없이 LIT 웹에서 예약하고, 예약 확인 이메일을 받는다. 짐을 맡기기 전엔 "정말 거기 있나, 제때 갈 수 있나"가 불안하다.

## 기능

### F1. 예약마다 대화방 하나
- 예약이 확정되면 그 예약의 대화방이 열린다. 짐을 찾은 뒤 24시간이 지나면 대화방이 닫힌다(읽기만 가능).
- 예약이 취소되면 대화방도 닫힌다.
- 대화방은 예약 정보(예약 번호·날짜·맡긴 짐 개수)를 맨 위에 보여 준다.

### F2. 자동 번역
- 보낸 사람이 자기 언어로 쓰면, 받는 사람에게는 받는 사람 언어로 번역해 보여 준다.
- 번역된 말풍선 아래에 "원문 보기"가 있어 원문을 펼쳐 볼 수 있다.
- 번역에 실패하면 원문을 그대로 보여 주고 "번역하지 못했어요"라고 표시한다.
- 손님 언어는 예약할 때 쓴 웹 언어(ko/en/ja/zh)를 따른다.

### F3. 빠른 답장
- 자주 쓰는 문장을 버튼으로 보낸다. 미리 4개 언어로 번역해 두어 번역 오류가 없다.
- 사장님 쪽: "네, 괜찮아요", "2층으로 오세요", "오늘은 OO시에 닫아요", "도착하면 카운터에 말씀해 주세요" — "오는 길 보내기"(안내 글·사진 카드)는 2차(#68 이후)로 미룸(2026-11-04 결정)
- 손님 쪽: "조금 늦을 것 같아요", "입구가 어디예요?", "지금 가는 중이에요", "일찍 찾으러 가도 되나요?"

### F4. 사장님 알림과 목록
- 새 메시지가 오면 점주 앱 푸시 알림이 간다.
- 예약 탭의 예약 행에 "답 필요" 표시가 붙는다.
- 홈에 "답 기다리는 메시지" 블록 — 답하지 않은 대화가 있을 때만 보인다.
- 사장님이 답하면 "답 필요"가 사라진다.

### F5. 손님 알림
- 손님은 앱이 없을 수 있으므로, 사장님 답이 오면 **예약 이메일 주소로 "가게에서 답장이 왔어요" 메일**을 보낸다(대화방으로 바로 가는 링크 포함). 10분 안에 여러 개가 오면 한 통으로 묶는다.
- 손님은 예약 완료 화면과 "내 예약" 화면에서 대화방에 들어간다.

### F6. 영업시간 밖 안내
- 영업시간이 아닐 때 손님이 보내면, 손님 화면에 "지금은 영업시간이 아니라 답이 늦을 수 있어요 · 내일 11시에 열어요"를 보여 준다.

## 규칙
- 메시지 하나는 1,000자까지.
- 닫힌 대화방에서는 보낼 수 없다 — 입력칸 대신 "대화가 끝났어요" 안내.
- 사진 보내기는 MVP에서 제외(오는 길 사진은 "오는 길 보내기" 카드로만).
- 대화 내용은 대화방이 닫히고 90일 뒤 삭제한다.
- 상대에게 전화번호·이메일을 보여 주지 않는다.

## MVP 제외
- 사진·파일 보내기, 음성 메시지
- 손님 앱(모바일 앱) 화면 — 웹 먼저
- 신고·차단(문의는 기존 고객센터로)

## 성공 지표
- 예약 중 메시지가 오간 비율
- 사장님 첫 답까지 걸린 시간(중앙값)
- 노쇼·헛걸음 관련 문의·낮은 별점 감소
